# 预案配置

随包已生成可直接使用的 `TF_CARD_ROOT/PLAN.BIN`。不修改参数时，直接复制TF素材即可。

需要调整时，编辑本目录 `plan_template.json`，在工程目录运行：

```powershell
python tools/make_plan.py
```

然后关闭开发板电源，把新生成的 `TF_CARD_ROOT/PLAN.BIN` 复制到FAT32卡根目录，安全弹出卡，再插卡上电。只改这些参数不需要重新综合或烧录bit。不要直接用记事本编辑二进制PLAN.BIN。

| 参数 | 随包默认值 | 可填内容 |
|---|---|---|
| normal_dwell_seconds | 5 | 正常页轮播间隔，3～30秒 |
| emergency_dwell_seconds | 2 | 应急内容页与地图轮播间隔，2～15秒 |
| default_volume | 2 | 0～4，对应屏幕第1～5档；0最大、4静音 |
| default_scene | campus | campus校园、drill演练、mall商场 |
| events中每项priority | 2 | 0～3，数字越大优先级越高 |
| events中每项audio | 见下表 | ALARM.PCM、FIRE.PCM、QUAKE.PCM、FLOOD.PCM |

`events`必须保留四项及其顺序。`name`是方便阅读的说明，实际按数组位置对应事件。

| 数组位置 | 校园/演练 | 商场 | 默认音频 |
|---|---|---|---|
| 第1项 | 火情 | 火情 | FIRE.PCM |
| 第2项 | 地震 | 人员拥挤 | QUAKE.PCM |
| 第3项 | 洪涝 | 停电故障 | FLOOD.PCM |
| 第4项 | 疏散 | 扶梯故障 | ALARM.PCM |

为保证事件语义对应，商场第2～4项始终使用ALARM.PCM，不套用校园的地震、洪涝语音；音频映射配置只影响校园/演练四事件及商场火情。四路音频映射是选择已有文件，不会生成新的语音。事件与图片的对应关系固定，不能通过预案更改。

发布事件时使用预案默认音量，之后仍可用KEY4调节；KEY3静音后，调大音量不会自动解除静音。自动/手动仍由KEY2长按切换，手动模式不会因到达轮播间隔而切页。

文件格式固定24字节：0～3为EPLN、4为版本1、5为启用位、6～9为时间/音量/场景、10为四项2位优先级、11为四项2位音频编号；12～22保留全零，23为前23字节的XOR8。音频编号依次为0通用警报、1火情、2地震、3洪涝。工具负责生成格式和校验。预案缺失或非法时使用bit内置默认值；非法预案可在状态诊断中表现为异常，缺失预案属于允许的默认启动方式。

TF素材读错后，终端保留已验证的SDRAM图片并使用片内警报降级，约5秒后重试初始化和扫描；仅补载失败或未完成的图片。此机制不修复损坏文件或接触不良，也不会把新卡内容覆盖到已缓存图片；更换批准素材后应断电重启。图片和音频校验常量与随包素材绑定，修改素材内容还需同步修改工程常量并重新综合。
