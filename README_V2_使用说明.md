# 多场景应急信息发布与疏散演练终端 V2

板卡：HX4S20C / EG4S20BG256。显示器接 HDMI_B。仅用板卡、已有 TF 卡和带扬声器的 HDMI 显示器，不需要传感器、网络、手机或额外模块。V1 可用工程保持在 `D:/completecode1/emergency_v1`。
本版提供校园应急、疏散演练、商场应急三个场景，在同一个 bit 中切换。校园与演练使用相同事件素材，地图标题分别为“校园疏散图”“疏散演练模式”；商场使用内置事件提示卡和“商场疏散图”。
## 烧录与素材

烧录本目录 `emergency_terminal_v2_hdmi_b.bit`，使用此前已跑通的配置 Flash 方式。下载完成后插好 TF 卡，断电再上电；若只下载 SRAM，断电后配置不会保留。

TF 卡仍是 FAT32，根目录包含十个素材和一个可选预案：NORMAL.BMP、SAFETY.BMP、FIRE.BMP、QUAKE.BMP、FLOOD.BMP、EVAC.BMP、ALARM.PCM、FIRE.PCM、QUAKE.PCM、FLOOD.PCM、PLAN.BIN。本次将两张日常图制作成缩放演示素材：NORMAL为320×240，SAFETY为800×600，增加源尺寸说明及四角标记；四张应急图仍为640×480，四路音频保持原文件。所有BMP均为24位、不压缩，FPGA统一缩放到640×480帧缓存；PCM是16kHz、8位有符号单声道原始数据。文件名不要改成中文，也不要放入子文件夹。缺少或损坏PLAN.BIN时自动使用bit内置默认值，不影响十个素材加载。

新bit和本包TF素材必须配套使用，不能只换图片而继续烧录旧bit。建议直接将包内TF_CARD_ROOT中的11个文件复制到TF卡根目录并覆盖同名文件，再安全弹出、插卡、断电重上电。旧版素材及bit仍保留在此前release目录。

## 图片缩放与一镜到底展示

两张日常图分别演示小图放大、大图缩小，显示输出均为640×480；图片左上角以单行文字标注源尺寸到输出尺寸，不使用说明方框，黄色四角标记用于观察画面内容完整性。放大使用最近邻采样，320×240图的细小文字会比高分辨率图粗，这是源像素数量减少的结果。没有新增运行时缩放按键，也没有增加帧缓存。

正常状态下确认顶栏为“手动”（若为自动，长按KEY2约1秒切换），短按KEY2切到NORMAL并拍摄尺寸标签及四角，再短按KEY2切到SAFETY拍摄第二组尺寸。约12秒即可连贯展示两个方向的适配，不用拔卡或更换bit。详细口播与步骤见《缩放适配演示说明.md》。预案仍保持正常轮播5秒、应急轮播2秒、发布音量3档。

上电前建议将 SW4 拨到低电平位置。前约两秒显示内置状态页，然后进入原来的日常轮播，TF 素材继续后台加载。SW4 若在上电时已经为高，不会自动发布事件，必须先拨低再拨高。开关高低以原理图连接为准，实板拨动方向请以首次演示验证，不依赖未经确认的 ON 字样。

**声音范围：**校园与演练的火情、地震、洪涝继续使用现有中文播报，疏散使用 ALARM.PCM。商场火情使用 FIRE.PCM；商场人员拥挤、停电、扶梯故障使用 ALARM.PCM 通用警报及对应屏幕处置提示，没有新增这三种事件的专属中文语音。不能用地震、洪涝语音代替商场事件播报。

## 拨码开关

| 开关 | 作用 | FPGA 引脚 |
|---|---|---|
| SW1 | 区域编码低位 | C8 |
| SW2 | 区域编码高位 | C7 |
| SW3 | 低：单区域危险；高：按SW2/SW1选择左右半区或全区危险 | C6 |
| SW4 | 第一次低→高预警；再次低→高确认发布 | C5 |

| SW3 | SW2 | SW1 | 危险区域 |
|---|---|---|---|
| 0 | 0 | 0 | A，左上 |
| 0 | 0 | 1 | B，右上 |
| 0 | 1 | 0 | C，左下 |
| 0 | 1 | 1 | D，右下 |
| 1 | 0 | 0 | 全部 A+B+C+D |
| 1 | 0 | 1 | 左半区 A+C |
| 1 | 1 | 0 | 右半区 B+D |
| 1 | 1 | 1 | 全部 A+B+C+D |

本版采用明确的演练规则：SW3为低时，由SW1/SW2选择单个危险区域；A/C危险则关闭左侧出口一，B/D危险则关闭右侧出口二。SW3为高时，SW2/SW1为01选左半区A+C，10选右半区B+D，00或11选四区全部危险。左半区危险推荐右侧出口二，右半区危险推荐左侧出口一；全部危险关闭两个出口，不画疏散箭头，并显示“通道受阻，等待指挥”。所有选中的危险区均闪烁红色。地图、状态页与历史页均标明单区字母、左半区、右半区或全部。地图底部持续显示黄色无障碍提示，提醒听障人员查看屏幕、行动不便人员就地求助，避免虚构未经现场确认的无障碍路线。

SW 是模拟输入，不是实际火灾/地震/水位检测器。地图是四区路线示意，不是实际校园或商场测绘，也不代表测得了可通行路线。发布事件时锁定场景和事件。事件中改变SW1～SW3，校园/商场场景须短按KEY3确认新路线，演练场景自动更新；确认路线不会改变原有静音状态。SW4 不负责解除或静音；保持高电平也不会反复发布。第一次SW4有效上升沿进入“预警待确认”，拨低后再拨高才发布，也可用KEY3短按完成第二次确认。

## 按键

短按在松开时执行，长按约一秒执行一次。
组合短按时两键在约200ms内一起按下、保持不足一秒再松开；先后松手不会触发单键操作，同时长按不会切换场景。

| 按键 | 正常模式 | 应急模式 |
|---|---|---|
| KEY1 | 全局复位 | 全局复位，清空易失记录 |
| KEY2 短按 | 切换 NORMAL / SAFETY | 切换原应急图片 / 动态疏散图；从状态/记录页短按回图片 |
| KEY2 长按 | 自动 / 手动切换 | 自动 / 手动切换，当前状态显示在屏幕顶栏 |
| KEY3 短按 | 第一次显示“确认发布”，第二次发布 | 路线待确认时只确认路线；否则确认并静音，保留警示及计时 |
| KEY3 长按 | 仅在当前场景的四个事件间循环 | 第一次显示“确认解除”，第二次解除 |
| KEY2+KEY3 同时短按 | 校园应急 → 疏散演练 → 商场应急，切换后选中该场景火情 | 状态页 → 历史页 → 原图片，不改变已发布场景 |
| KEY4 长按 | 选择亮度、对比度、音量 | 相同 |
| KEY4 短按 | 调节当前项目，共五档循环递减 | 相同 |

上电默认校园火情。先同时短按KEY2+KEY3选择校园应急、疏散演练或商场应急；每次切换场景都选中该场景火情，避免继承不对应的事件。再长按KEY3在当前场景内选择四个事件：校园/演练为火情、地震、洪涝、疏散，商场为火情、人员拥挤、停电故障、扶梯故障。屏幕左上第二行显示场景和所选事件，右侧显示自动或手动；场景或事件变更都会取消旧的发布确认。

每次发布新事件默认显示动态疏散图，默认音量和轮播时间由 PLAN.BIN 决定，事件与图片对应关系为片内固定安全映射；随包默认值仍是音量第三档、正常页约5秒、应急内容页/地图约2秒。短按KEY2切换应急内容页/地图；校园与演练的内容页使用对应BMP，商场内容页由片内逻辑绘制事件图标、居中的中英文标题和处置提示。声音独立于当前显示页面运行。正常和应急状态都可长按KEY2切换自动/手动；应急状态同时短按KEY2+KEY3依次查看状态页、历史页并返回图片，查看状态或历史时暂停切页。

KEY3短按静音后，改变音量不会解除静音；解除并重新发布才重新播报。第一次长按KEY3进入解除确认时，事件及原有声音状态继续保持；第二次长按才解除。事件不会因计时结束或SW4关闭而自动解除。

六位数码管从左到右：`d`正常 / `E`应急；事件编号1～4；音量档位；亮度档位；对比度档位；正在调的项目1亮度、2对比度、3音量。校园/演练事件编号依次为火情、地震、洪涝、疏散；商场依次为火情、人员拥挤、停电故障、扶梯故障。场景名称看屏幕，数码管不另占一位显示场景。

亮度/对比度1档最强、初始五格，按键逐档减少，第5档后循环回第1档。音量1档最大、5档静音，发布时恢复预案默认音量，随包为3档三格。例如 `E13113` 表示应急、事件1、音量3档、亮度1档、对比度1档、当前调节音量。应急KEY3静音与音量档位独立，静音后仍显示原档位。

## 新增功能与边界

1. 三场景与实时图形疏散：四区危险选择、出口阻断、移动箭头、双出口关闭提示，商场事件图文卡不占新增 SDRAM 图片帧。六个32位帧缓存共7372800字节，保持不变。
2. 无外设模拟联动：四个开关同步、20ms 整组消抖、SW4上电高电平保护、发布参数锁定。
3. 故障降级：地图和应急文字由片内逻辑/字库生成，TF 卡素材缺失也能显示；音频文件失败或连续约250ms取不到PCM时，切换内置800/1200Hz交替脉冲警报，仍受音量和KEY3静音控制。恢复PCM后自动恢复原播报，不生成替代中文语音。
4. 无障碍视觉提示：同一关键信息同时使用中文、英文和简明符号/方向箭头，配合颜色、危险感叹号、闪烁边框与声音；静音后仍保持强视觉报警。出口一/二可用分别对应“EXIT 1 OPEN <”“EXIT 2 OPEN >”及路线箭头；封闭出口显示白色叉号，无可用出口时不显示疏散箭头，以中英文文字提示等待现场指挥。发布/解除确认页使用琥珀/酒红底色，显示大图标、中文动作、英文动作、当前事件、中文按键说明和流程提示；顶栏保留场景、事件、自动/手动及原有五档调节条。
5. 状态页：显示时钟锁定、SDRAM控制器初始化、卡初始化、图片完整提交数0～6、音频文件登记数0～4，并直接显示当前事件类型、危险范围、待确认/已静音状态和持续时间。前三项1表示当前状态成立，0表示尚未成立；音频数量只是找到文件，不证明扬声器实际出声。不是完整SDRAM遍历自检，不检测屏幕是否真正亮起。
6. 四条易失记录：最新在上，记录场景编码、事件类型、危险范围、待确认/已静音/已解除/已替换和用时。历史页根据记录场景显示对应事件名称；不另显示校园/演练字样。当前事件时间持续更新，单位秒，最大999；已接受的路线变更同步更新当前记录的危险范围。这里“待确认”表示已发布但尚未按KEY3静音，不是发布前预警。高优先级串口事件替换原事件时标记已替换。记录在FPGA寄存器中，复位/断电清空，不写TF，不依赖RTC。
7. 可配置预案：FPGA从TF根目录读取固定24字节、带版本号和XOR8的 PLAN.BIN，可配置正常/应急轮播秒数、上电场景、默认音量、四事件优先级和四路音频映射；字节12～22保留且必须全零。事件与图片对应关系固定，防止错误配置把灾种和画面错配。不解析任意文本，也不会突破固定缓存。配置缺失、版本错误、范围越界、保留位非零或校验失败时使用内置默认值。
8. 运行期故障自愈：扇区、音频流或播放器发生错误时，立即停止TF音频访问并由片上警报接管；已经通过CRC并提交的SDRAM画面继续显示。系统等待约5秒后自动重新初始化TF卡并重扫根目录；恢复扫描跳过仍在SDRAM中的已验证图片，只补载此前失败或未完成的页面，避免覆盖正在显示的画面。恢复成功后重新允许TF音频；若仍失败则继续约每5秒重试。完全没有可用图片时仍显示片内降级页面，不黑屏、不死机。

发布前确认、解除确认只作用于本地按键和SW4模拟流程。原UART维护协议保留直接发布/解除、ID校验、优先级与去重语义，不属于本地二次确认流程。

## 四项智能增强

### 1. 四级可解释预警

屏幕右上角持续显示中文“预警等级”和数字0～3，并用颜色加强区分：蓝色0级为正常，黄色1级为发布待确认，橙色2级为单区域应急，红色3级为左半区、右半区或全部区域危险。标牌覆盖旧素材计数完整区域，最右侧不再残留白色。等级跟随已接受的路线更新，半区/全区改回单区后回到2级，不再因持续60秒自动升为3级。校园/商场须KEY3确认路线后才改变等级，演练则自动更新；待确认期间保持原路线和原等级。这是模拟演示规则，不冒充真实传感器判断或官方灾情等级。

### 2. 自适应路线与人工确认

系统对当前危险区域计算推荐出口和路线安全分。应急发布后再改变SW1～SW3时：

- 疏散演练场景自动采用新危险区并重新绘制路线，同时累计“路线调整”次数；
- 校园应急、商场应急保持原路线，画面显示“路线待确认 / ROUTE UPDATE”，短按KEY3后才采用新路线；该次按键只确认路线，不会静音，再次短按KEY3才确认事件并静音；
- 两个出口均不可用时路线分为0，不显示绿色箭头，并提示等待现场指挥。

单区域路线分为95，左右半区为70，全部危险为0。待确认时将拨码恢复到已接受的位置会撤销路线待确认，避免残留提示。路线确认保持原有声音状态：正在播报则继续，原先已静音则保持静音。

这样可以演示自动重规划，同时避免真实发布模式因拨码抖动或误碰突然改变疏散方向。

### 3. 演练量化评估

在“疏散演练”场景完成两次长按KEY3解除后，自动显示评估报告。报告包含发布确认用时、静音响应时间、演练总时间、路线调整次数、操作修正记录及0～100分；三个时间值均标注“秒”，操作修正记录显示“有/无”，路线调整次数超过9次时画面按9显示，避免数字越界变成字母。90分及以上为优秀，75～89分为合格，低于75分为需改进，页面底部只显示一次评价。扣分项为确认超过5/10秒、静音超过15秒或未静音、总时长超过180秒、解除时仍有路线待确认、多次路线调整以及确认后又取消修改。短按KEY2退出报告。分数用于演示操作流程，不是对真实人员疏散安全的认证。

### 4. TF素材完整性诊断

六张BMP在读取、格式解码、完整写入的同时计算片上XOR8，只有与本版批准素材一致才允许显示。四路PCM在每个文件完整播放一轮后完成片上XOR8校验；尚未播放完整时显示为未完成校验，不等同于损坏。状态页显示图片通过数`x/6`、音频通过数`x/4`，出现错误时显示“校验失败”；图片错误使用内置图形替代，音频错误触发内置警报降级。交付打包工具另外逐文件执行SHA-256和ZIP CRC32检查，构成“片上快速诊断+离线强校验”的分层方案。

片上XOR8值与当前十个TF素材绑定，因此不能自行编辑文件内容后继续使用旧bit。若以后更换图片或音频，必须重新计算CRC常量、重新综合并重新烧录。文件名、目录、BMP/PCM格式要求仍与前文一致。

保留同一配置中的 FAT32/BMP/SDRAM/HDMI、手动自动轮播、中文滚动字幕、切换特效、缩放解码、亮度对比度OSD及HDMI48kHz音频。音频可视化使用2像素细竖线，相邻线保留2像素透明间隔，以中线为中心上下伸缩；中心为鲜亮青绿色，向上下峰值连续渐变为亮黄色，总宽512像素、高32像素。无独立背景、边框、基线或“音频”文字，竖线内部没有分节断口。使用实际输出PCM最近32个1ms片段的峰值，随音量及播报起伏，不标为频谱。校园/演练四个应急内容页均显示在图标下方、底部提示框上方的空白带（x64～575、y364～395），商场四个应急内容页均显示在警示三角上方（x64～575、y64～95），不遮挡处置文字或疏散箭头。静音或PCM静默时幅度条消失，闪烁边框与中英文疏散提示继续。地图、状态、记录、评分和二次确认页不叠加音频条。应急关键提示采用中文、英文和简明图标/方向箭头同屏表达。

## 三分钟演示

1. SW1～SW4均低，上电看到状态数值，再进入两张日常图片轮播。使用状态页检查素材通过数6/6，右上角已改为预警等级。
2. 正常状态同时短按KEY2+KEY3选场景，长按KEY3选当前场景事件，看屏幕场景名及数码管第二位1～4。SW1/SW2选区域，SW3先低，KEY3短按两次：先预警再发布。校园/演练火情、地震、洪涝应有对应中文播报、红色区域和绿色箭头。
3. 短按KEY2查看应急图片/波形，再短按回地图；长按KEY2检查自动/手动切换；同时短按KEY2+KEY3看状态，再次组合短按看记录。
4. 短按KEY3确认：声音停止，事件保留且边框继续闪烁。长按KEY3两次，先确认解除再回日常。
5. 在校园应急状态改变SW1～SW3，确认路线保持不变且出现中英文“路线待确认”，短按KEY3后路线才更新；在疏散演练中重复操作，确认路线自动更新。
6. 在疏散演练中解除事件，查看演练评分页，短按KEY2退出。
7. SW4先拨低，SW1/SW2均低、SW3拨高，SW4执行高→低→高：四个区域全部红色闪烁，两出口关闭，只显示受阻提示、不画绿箭头；状态与历史页区域显示“全部”。再试SW3/SW2/SW1为101（左半区）和110（右半区），检查两块危险区域、推荐出口及3级预警；改回单区并确认后预警应回到2级。
8. 正常模式同时短按KEY2+KEY3切到商场，再长按KEY3选人员拥挤，短按KEY3两次发布，应看到商场地图和对应图文卡轮播，听到通用警报，不应播出地震语音。
9. 故障降级演示：先关闭电源并安全取出TF卡，再上电、KEY3短按两次发布事件，检查内置图形及合成警报。故障自愈可在工程测试中模拟运行期读错；实板若要演示重新插卡，建议使用带机械锁的TF座并避免在写卡时操作，本终端只读TF。重新插入后约5秒自动重扫，无需复位；若卡座接触导致初始化仍失败，会继续周期重试。

不加入自动解除警报的定时演示脚本，整个“发布—确认—解除”流程由操作者明确控制。

## 赛题与硬件资料

赛题解析第6页/第19页关于OSD调节允许拨码开关或按键，因此可使用板上SW。基础与拓展功能仍保留在同一最终bit中；SW在本版承担模拟输入/演练控制，不能在答辩中声称接入了实体传感器。

SW 引脚与电平来自赛题2026官方网盘 `HX4S20_Contest_202606/3_原理图/开发板原理图/2_FPGA.pdf` 和 `6_EX_DEVICE.pdf`：SW_1～4 经RN38到SWKEY_1～4，分别C8/C7/C6/C5，开关在3V3/GND间切换。网络页面预览与放大核对图保存在工作区 `board_docs`，没有使用其他型号开发板引脚。

本版仍需在你的实板进行Flash启动、开关方向、六图、音量、静音解除及HDMI声音验收。软件仿真和时序通过不能替代实板验证。

## 源码与复现

`emergency_v2_source.zip` 是自包含源码包，解压后可在 TD 打开 `project/emergency_terminal.al`，器件选择 EG4S20BG256，顶层为 emergency_terminal_top。工程引用均为包内相对路径，不需要外部 V1 目录。当前新增逻辑使用 Verilog，不需要软核或软件处理器。

修改 `config/plan_template.json` 后运行 `python tools/make_plan.py`，即可重新生成 `TF_CARD_ROOT/PLAN.BIN`，不需要重新综合bit。音量值0～4对应从最大到静音，轮播范围分别为正常3～30秒、应急2～15秒；音频名称必须从模板已有文件名中选择，图片对应关系不可配置。四路音频映射用于校园/演练事件及商场火情；商场人员拥挤、停电、扶梯故障固定使用通用警报，避免预案把校园灾种语音带入商场。

已交付 bit 使用 `tools/rebuild.py` 中的布局布线与保持时间修复设置生成。复现同一路径可在解压目录执行 `python tools/rebuild.py --td D:/ANLUTD --seed 3`；运行 `powershell -ExecutionPolicy Bypass -File tools/run_tests.ps1 -Test All` 可执行17项回归，需要 Icarus Verilog，默认位置 D:/iverilog/bin。字库已经包含在源码，不需要重新生成；`make_safety_font.py` 仅用于后续修改新增页文字。

最终资源、时序和各项测试证据见 `验证记录_V2.md` 与源码包 `reports`。原 V1 素材重绘/工程生成脚本不包含在交付源码包中，以免覆盖本版已核对的引脚和顶层逻辑。
